# 🎓 Student Record Management System (Python)

A menu-driven Student Record Management System built in Python. This project demonstrates the use of dictionaries, functions, loops, tuples, input validation, and basic data analysis.

## ✨ Features

- ➕ Add new student records
- 🔍 Search students by ID
- 🗑️ Delete student records
- ✏️ Update student marks
- 📋 Display all student records
- 📈 Show highest marks
- 📉 Show lowest marks
- 📊 Calculate average marks
- 🏆 Display student grades
- 🥇 Show the top 3 scores
- ✅ Input validation for marks (0–1200)

## 🛠️ Technologies Used

- Python 3
- Dictionaries
- Tuples
- Lists
- Functions
- Loops
- Conditional Statements

## 📂 Data Structure

Each student is stored in a dictionary.

Example:

```python
students = {
    "101": ("Ali", 1050),
    "102": ("Sara", 980)
}
```

Where:

- **Key** → Student ID
- **Value** → `(Student Name, Marks)`

## 📖 Menu

```
1. Add Student
2. Search Student
3. Delete Student
4. Update Marks
5. Display All Students
6. Highest Marks
7. Lowest Marks
8. Average Marks
9. Grade Distribution
10. Top 3 Scores
11. Exit
```
